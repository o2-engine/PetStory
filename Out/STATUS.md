**SDF-подход (по фидбеку):** рендер разделён на слои «круглое основание + иконка», для обоих считаются signed distance fields (текстура R=DF круга, G=DF иконки). Шейдер chip_sdf строит арт конструктивно: градиент тела по свету, полумесяцы светлой/тёмной кромки, двухполосный засвет снизу-справа, блик с собственным мировым направлением, для иконки — градиент, кромочные свет/тень/отсвет по ∇DF, DF-дуга-блик и офсетная мягкая тень на основании. Все направления мировые → при вращении спрайта вращается только сама иконка. Цвета слоёв ИЗМЕРЕНЫ из референса, геометрия дофичена стадийным оптимизатором. Ворота ужесточены: mean≤3.5%, bad(>20%)≤0.5%, кольцо≤2.5%. Лист отложен (не в воротах).
